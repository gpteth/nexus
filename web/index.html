Frequently asked questions

Do I have to change my application code?

No. Nexus speaks the OpenAI API, so you only change the base URL and use a Nexus API key. All your existing requests keep working.

Which providers are supported?

Any endpoint that follows the OpenAI Chat protocol — including OpenAI, DeepSeek, vLLM and Ollama — through a generic adapter. Heterogeneous protocols get dedicated adapters on the roadmap.

What happens when an upstream fails?

The circuit breaker opens and the gateway fails over to a healthy upstream in the same model group, with retries and backoff. Your users see a response, not an error.

Is it really production ready?

The core gateway ships with tests, race detection, an end-to-end smoke suite and Docker support. Persistent storage, a management console and compute orchestration are on the public roadmap.

Can I self-host without any external database?

Yes. The data plane is stateless and the in-memory store works out of the box. SQLite/Postgres adapters are available as pluggable backends when you need durable persistence.
